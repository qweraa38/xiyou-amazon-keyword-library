# 西柚 Amazon.de 关键词词库 Skill

这是一个用于通过西柚（Xiyou）调研 Amazon.de 竞品 ASIN、建立关键词库并输出 Excel 的 Codex Skill。

## 适用场景

当用户提出以下需求时使用本 Skill：

- 调研一个或多个 Amazon.de ASIN 的关键词
- 建立竞品关键词库
- 调研当前关键词、去年旺季关键词、销量、流量和市场数据
- 要求调用西柚的全部可用数据接口
- 要求每个关键词页面都增加中文释义

## 默认研究范围

- 站点：Amazon.de
- 当前数据：西柚返回的最新可用快照
- 去年旺季：上一年度 10 月至 12 月；例如当前为 2026 年时，默认调研 2025-10 至 2025-12
- ASIN：重复 ASIN 会去重分析，但在结果中保留原始输入数量、去重数量和重复清单
- 关键词：保留原始完整短语，按大小写不敏感去重，不拆分短语、不词干化、不合并拼写变体

## 调研数据

在接口可用时，尽量完整获取并保留以下数据：

1. 商品信息、品牌、价格、评分、类目树、尺寸/重量和变体
2. 当前多 ASIN 关键词对比
3. 去年旺季月度关键词对比
4. 单 ASIN 当前关键词、去年旺季关键词和近 30 天日级反查关键词
5. 关键词市场信息：周搜索量、ABA 排名、CPC、建议竞价、竞争难度、点击转化率、自然位轮换和头部 ASIN 占比
6. 当前 30 天订单/销量估算和去年旺季月度订单趋势
7. 当前整体流量、日/周/月流量趋势及自然流量/广告流量结构
8. 关键词数量趋势、BSR 趋势、价格/评分/评论趋势
9. 商品信息变更、广告变更和变体关系
10. 当前与去年旺季 ABA 趋势

如果接口返回空结果、日期限制或不可用提示，必须保留该状态，不能用当前数据替代历史数据，也不能补造关键词或销量。

## Excel 输出要求

如果已有历史词库模板，默认沿用历史模板，不重新设计成另一种版式：保留原工作表顺序、表名、表头位置、冻结窗格和字段口径。所有非空明细表都要使用 Excel 原生表格筛选，导出后必须确认筛选下拉仍然存在；不能只在生成器预览里看起来像表格。

关键词库至少应包含：

- 关键词总览
- 关键词库_当前
- 关键词库_去年旺季
- 每个 ASIN 的当前关键词证据页
- 每个 ASIN 的去年旺季关键词证据页
- 销量与商品信息
- 流量结构和流量趋势
- 订单趋势、BSR 趋势、关键词数量趋势
- 商品信息趋势、商品信息变更、广告变更、变体关系
- ABA 趋势_当前和 ABA 趋势_去年旺季
- 接口返回状态
- 口径与说明

趋势页还要提供原生可编辑的可视化图表，而不是截图：

- 订单趋势：订单量折线图或柱状图
- 关键词数量趋势：自然词/广告词折线图
- 月度、周度、日度流量：自然/广告流量折线图
- BSR 趋势：代表类目排名折线图
- 商品信息趋势：价格和星级折线图
- 数据适合时，增加当前订单与去年旺季订单对比柱状图

图表必须绑定到同一工作表内可核对的辅助数据区，保留完整原始明细和筛选功能。日度数据过密时，图表可以只展示最近 60–90 个观测点，但要在标题或说明中标明范围，不能删除全量数据。

每一个包含关键词的工作表都必须紧邻原始关键词右侧增加 `中文释义` 列。原始德语/英语关键词保持不变；品牌名、IP 名称、拼写变体和无法可靠翻译的片段要标注为保留，不得臆造翻译。

## 数据口径

- 西柚订单/销量是对应时间窗口的估算值，不等同于 Seller Central 确认销量、销售额、利润或收入。
- 关键词市场指标是关键词层面的市场数据，不等同于某个 ASIN 自身的流量。
- 竞品标题、关键词和商品信息是观察结果，不是用户产品事实的证明。
- 结果中区分当前数据、去年旺季数据、单 ASIN 证据、汇总关键词和接口限制。

## 使用示例

可以直接在 Codex 中提出类似请求：

```text
用西柚调研这些 Amazon.de ASIN：B0XXXXXXXX、B0YYYYYYYY。
获取当前和去年 10-12 月旺季的全部可用关键词、销量、流量、市场指标和趋势数据，
建立 Excel 关键词库；每一个关键词页面都在关键词右侧增加中文释义。
```

如果用户指定其他旺季年份或月份，以用户指定的时间范围为准。

## 依赖

- 可用的西柚/Xiyou Amazon 数据接口
- Amazon.de 研究权限
- 用于生成和校验 `.xlsx` 的表格工作流

本 Skill 不上传 Amazon Listing，不替用户虚构产品事实，也不把竞品数据直接当作用户产品声明。
